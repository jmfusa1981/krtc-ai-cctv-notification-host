# Manual Event Broadcast V1

- Dashboard event manual broadcast no longer requires an existing BroadcastRule.
- Clicking Manual Broadcast opens a modal for Speaker and Audio File selection.
- A matching BroadcastRule is used only to preselect defaults.
- Manual selection creates a BroadcastLog without creating a new BroadcastRule.
- PJSIP mode blocks offline speakers with an explicit error.
- Simulation mode remains available for UI and workflow testing.
